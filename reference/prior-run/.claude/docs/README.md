# Documentation Structure

This folder contains project guidance used for Mule-to-Spring Boot migration.

## Folders

- `standards/` - coding and API implementation standards.
- `testing/` - testing strategy and test guidance.
- `troubleshooting/` - known issues and diagnostics.

## Claude integration

- Use `CLAUDE.md` for repository-level Claude instructions.
- Use `.claude/commands/` for command routing.
- Keep `.claude/docs/*` as the canonical migration and engineering standards for Claude agents.
