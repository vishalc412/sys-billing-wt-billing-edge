# Agent Prompt Files

This folder contains migration agent specifications used during conversion and implementation.

## Files

- `agent.md` - Agent schemas, inventory/report structure, conversion mappings, validation checklist.
- `agent_task.md` - Step-by-step execution rules for automated agent commands.

Keep these files focused on execution instructions; keep implementation standards under `../docs/standards/`.

## Claude entry points

- Repository-level Claude guidance lives in `CLAUDE.md`.
- Claude command routing is available at `.claude/commands/`.
